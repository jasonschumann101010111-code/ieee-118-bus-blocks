## AI Taxonomy Overview

### Layers of AI

1. **Artificial Intelligence (AI)**
   - Broadest category
   - Computational systems designed to perform intelligent tasks
   - Examples: chatbots, recommendation systems, autonomous vehicles

2. **Machine Learning (ML)**
   - Algorithms that learn patterns from data
   - No explicit programming for every scenario
   - Examples: classification, regression, clustering

3. **Deep Learning (DL)**
   - Uses multi-layered artificial neural networks
   - Inspired by biological neural structures
   - Examples: CNNs, RNNs, Transformers

4. **Generative AI (GenAI)**
   - Models that create new content
   - Can generate text, images, code, audio, and more
   - Examples: GPT, DALL-E, Claude, Copilot

---

## Key Distinctions

| Layer | Focus | Method | Output |
|-------|-------|--------|--------|
| AI | Smart systems | Various | Decisions, predictions |
| ML | Learning from data | Statistical | Learned models |
| DL | Neural networks | Layers & activations | Feature representations |
| GenAI | Content creation | Large trained models | New, original content |

---

## Applications

- **AI**: Game playing, scheduling, optimization
- **ML**: Spam detection, price prediction, fraud detection
- **DL**: Image recognition, natural language, video analysis
- **GenAI**: Text generation, code synthesis, creative content
